PLAN A Add it as a connector

  1. Open ChatGPT on a computer, not the phone. Setup is desktop-only; once it's done it works everywhere including your phone.
  2. Click your name, bottom left, then Settings.
  3. Look for Connectors (some accounts call it Apps, and it may sit under Advanced or Developer mode - if there's a Developer mode switch, turn it on first).
  4. Choose Add or Create, and pick the option for a custom or your-own connector.
  5. Paste the address above. Name it anything - Owl House is fine.
  6. For authentication choose API key or Bearer and paste the token above.
  7. Save. It should list about twenty tools. If it does, you're done.

PLAN B Add it as a custom GPT instead

Use this if Plan A's screen isn't there, or it refuses the address.

  1. Go to chatgpt.com/gpts/editor to create a new GPT.
  2. Give it a name and a short description - My Owl House assistant.
  3. Open the Configure tab, scroll to the bottom, and click Create new action.
  4. Click Import from URL and paste: https://reai.owlhouserealty.com/gpt/openapi.json
  5. Under Authentication choose API Key, set Auth Type to Bearer, and paste the token.
  6. Save, then click Create or Update at the top right.

You'll then use that GPT rather than plain ChatGPT when you want your own data. It's one extra tap from the sidebar.
